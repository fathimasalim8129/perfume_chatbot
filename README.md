# Perfume Recommendation Chatbot

This project is an AI-based chatbot that recommends perfumes based on user preferences such as fragrance type, occasion, gender, and budget.

## Features
- Conversational chatbot interface
- Personalized perfume recommendations
- Rule-based / ML-based logic
- Simple and user-friendly design

## Technologies Used
- Python
- NLP (basic)
- Flask / Streamlit (if used)
- GitHub for version control

## How to Run
1. Clone the repository
2. Install dependencies using `requirements.txt`
3. Run the main Python file

## Project Purpose
This project was developed as part of an IBM Skill build internship project in AI & ML.
